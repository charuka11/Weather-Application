# WeatherNow 🌤️

**WeatherNow** is a modern, responsive weather application that provides real-time weather updates and a 7-day forecast for any city around the world. It features a clean, user-friendly interface with dynamic weather icons.

## ✨ Features

* **City Search:** Search for current weather conditions in any city globally.
* **Current Weather Details:** View real-time temperature, "feels like" temperature, humidity, wind speed, and precipitation.
* **7-Day Forecast:** Get a detailed forecast for the next 6 days, including daily maximum and minimum temperatures.
* **Dynamic Icons:** Weather conditions (Clear, Cloudy, Rainy, Snowy, etc.) are represented with matching emojis/icons.
* **Responsive Design:** Beautifully designed to work seamlessly on desktop, tablet, and mobile devices.
* **Auto-Location Load:** Automatically fetches and displays the weather for a default city (Colombo) on page load.

## 🛠️ Technologies Used

* **React.js:** For building the interactive user interface and managing state.
* **CSS3:** For custom styling, responsive layouts, and modern UI design.
* **Open-Meteo API:** Used for fetching accurate geocoding data and real-time weather forecasts.
* **Vite :** For the development environment and build process.
